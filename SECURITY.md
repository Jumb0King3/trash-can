# Security Policy

## Supported versions

Only the latest release of this mod is supported. Please update to the newest version before reporting a problem.

## Reporting a vulnerability

Please do not report security problems as a public issue.

Use the **Security** tab of this repository and choose **Report a vulnerability**. This sends the report privately so it can be looked at and fixed before details are made public.

Normal bugs (crashes, wrong behaviour, compatibility problems) are not security issues. Please report those on the **Issues** tab using the bug report form.

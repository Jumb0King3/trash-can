# Trash Can

Trash Can adds a trash can for getting rid of items you don't want.

**How to use it**

- Right-click the trash can to open it. The lid swings open and you get 16 slots, just like a chest.
- Put in anything you want to get rid of.
- Press "Delete items", then press it again within 3 seconds to confirm. Everything inside is deleted for good, and you get a chat message saying how much was removed.
- Closing the trash can doesn't delete anything. Items stay inside until someone presses Delete, so you can change your mind and take them back out.

**Crafting**

Any one wood plus any one metal: 5 boards of the same wood and 1 ingot. There are 14 woods (including aged and very aged) and 5 metals (copper, tin bronze, bismuth bronze, black bronze and iron), so there are 70 different looks to choose from.

**Good to know**

- In claimed land, only players allowed to use blocks there can open it or delete what's inside.
- There's no undo. Once you confirm the delete, the items are gone.

Install it on the server. Players joining get it automatically.

## Report a problem

Please report bugs on the [Issues](../../issues) tab and include your game version, the mod version and your log. Security problems: see [SECURITY.md](SECURITY.md).

**Where to find your log**

The logs are in the Vintage Story data folder, in a folder called `Logs`:

| System | Data folder |
|---|---|
| Windows | `%appdata%\VintagestoryData` (paste that into the File Explorer address bar) |
| Linux | `~/.config/VintagestoryData` |
| Mac | `~/Library/Application Support/VintagestoryData` |

- **Playing on a server:** send `client-main.log` from your own game. If you run the server, also send `server-main.log` from the server's data folder.
- **Singleplayer:** `client-main.log` and `server-main.log` are both in the data folder above.
- Attach the file to the issue (drag it into the box), or paste just the lines with errors. Reproduce the problem first, then grab the log straight afterwards, so the error is near the end.
